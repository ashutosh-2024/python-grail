How to use this

Open an entry and read the snippet before you expand the output. Commit to an answer out loud — the whole value is in the gap between what you predicted and what CPython actually did. If the two match, you already own that rule and you can move on in ten seconds.

Each entry closes with a fix section showing the version you would want in real code, and links into the language reference so you can confirm the behaviour is specified rather than accidental.
